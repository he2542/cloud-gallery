# v0.1.0 本地验证

此为初版记录。最新 v0.1.1 已通过 28 项后端测试及新增异常与子路径浏览器验证，详见 [自检报告](self-check.md)。

验证日期：2026-10-03。此记录不代表生产部署成功或 PostgreSQL 实例已经验收。

- 后端：11 项 pytest 测试全部通过，使用独立临时 SQLite 数据库。
- 覆盖首次创建账户、会话退出与过期、禁用账户、登录限速、CSRF / Origin。
- 验证两个账户间的私有列表、标签、用量、原图和缩略图隔离，以及公开空间切换为私有后的访问。
- 验证图片校验、像素上限、全站配额、标签去重、字面百分号搜索、分页、删除后文件和配额回收。
- 两个并发上传不会突破配额；两个并发删除仅扣减一次计数。
- 示例图片可重复生成且不会重复插入，示例账户禁止登录，清理命令可完整回收文件和配额。
- 前端 TypeScript 检查和 Vite 生产构建通过；包含全部开发依赖的 npm audit 报告 0 个已知漏洞（仅表示检查时的结果）。
- Chrome 真实浏览器完成 8 项流程：示例缩略图展示、创建账户、默认私有上传、修改与搜索、创建空间、标签索引、退出后私有地址被拒绝、手机导航与无横向溢出。
- 手机检查视口 390 × 844，桌面 1440 × 1000。测试账户与测试图片在验证完成后清理，不留下预设登录密码。
