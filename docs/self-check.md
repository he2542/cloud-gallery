## 结论

本地功能在修复后通过本次检查。原来的正常流程测试不能覆盖全部边界，本次确实复现了问题，并补上对应测试。此结论不代表生产环境已通过验收。

## 已发现并修复的问题

| 触发情况 | 原来表现 | 修复 |
|---|---|---|
| 透明 PNG 带 ICC 信息 | 全尺寸图仍保留部分输入元数据 | 清空处理图的信息字段；测试透明度与元数据 |
| 环境名、布尔值、Origin 或数据库类型填错 | 配置未及时拒绝，生产保护可能不符合预期 | 启动时严格校验；拒绝非持久化 SQLite |
| 非 ASCII CSRF 请求头 | 字符串比较抛错，返回服务器错误 | 统一作为无效请求返回 403 |
| 两次并发创建第 20 个空间 | 两个请求均成功，突破数量限制 | 在事务中锁定账户写入后再计数创建 |
| 删除第 2 页唯一图片，总量从 25 变为 24 | 空白页且分页入口消失 | 自动回到有效页；实测显示 24 张 |
| 退出登录后图库请求失败 | 已加载的 24 张私有图片信息仍留在页面 | 同步清理身份相关界面；实测剩余 0 张 |
| 身份失效后提交上传 | 页面仍维持旧登录状态 | 401 清理会话状态并重新打开登录 |
| 已选图片后又选无效文件 | 前一个文件仍可能被上传 | 清除原选择，禁用上传直至重新选有效文件 |
| 在指定空间内打开上传 | 初始目标仍是第一个私有空间 | 优先选择当前具有上传权限的空间 |
| 清除搜索条件 | 搜索框文字与地址条件不同步 | 搜索框跟随路由查询状态 |
| 空白标题或文本含 NUL | 校验不完整；PostgreSQL 可能拒绝存储 | 规范化名称并拒绝非法字符；查询条件同样校验 |
| 登录输入触发参数校验错误 | 默认错误数据可能回传提交的密码值 | 错误响应保留字段位置、类型、提示，去掉原始输入 |
| Windows 路径含空格、启动尚未就绪 | 参数解析或就绪提示不可靠 | 引用 Vite 路径并等待真实健康检查；记录实际 API PID |

当前用户预览数据没有用于浏览器自检，浏览器使用独立端口、数据库和图片目录。临时测试服务在验收后停止。

## 仍需生产验收

真实 PostgreSQL 连接与事务行为、OpenResty 容器到 API 的网络、systemd 资源限制、备份恢复和真实负载尚未验收。本次子路径验证使用 Vite 代理，不能替代服务器上的 OpenResty 验证。

init-db 用于新库建表，已有表升级仍需引入版本化迁移。数据库与文件系统没有跨系统原子事务，异常断电或磁盘故障仍可能产生孤立文件，正式部署需要对账与备份。

当前框架与已实现接口详见 [项目框架](project-framework.md)。
